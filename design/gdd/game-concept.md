# 末世废土 —— 游戏概念文档

> rigor: standard · brainstorm 产物 · 日期 2026-10-10
> 暂定名《末世废土》，可改。本文件是后续所有 GDD、美术圣经、架构决策的上游依据。

---

## 1. 一句话卖点

**在 8000×8000 格的无缝废土里，白天翻遍每一间随机生成的屋子搜刮物资、下矿井挖矿、钓鱼炼金，天黑前赶回据点——因为尸潮不等人。**

玩家 = 一名幸存者。做什么 = 探索/搜刮/制造/加固据点。为什么上瘾 = 每一次开门都是一次 loot 抽奖，而每一次外出都在和天黑倒计时赌博。

## 2. 设计支柱（冲突时按此裁决）

| # | 支柱 | 含义 | 反例（不做） |
| --- | --- | --- | --- |
| P1 | **世界是真的很大** | 8000×8000 格连续无缝，走到哪生成到哪，没有加载条、没有区域切换 | 分章节关卡、传送点切图 |
| P2 | **每个容器都值得按 E** | 房屋随机生成 + 容器个性化 loot，搜刮是核心快感来源 | 固定手工摆放的宝箱、无意义的空柜子 |
| P3 | **垂直空间是真的** | X/Y 是地面，Z 是楼层与地下矿井，上下都有内容 | 只有一层的平面图、地下只是贴图 |
| P4 | **压力来自时钟，不是血量** | 白天低压经营、夜晚高压防守，尸潮把"出门"变成一次风险决策 | 单调的刷怪、无节奏的随机遇敌 |

## 3. 平台与技术栈

- **Web / HTML5 Canvas 2D**，纯 JS，无引擎、无构建依赖，双击 `index.html` 即可运行
- 代码根 `src/`，测试根 `tests/`，数据 `src/data/*.json`
- 渲染：45° 俯角斜视，等距 2:1 菱形瓦片；`requestAnimationFrame` + delta time
- 目标：1920×1080 下稳定 60 FPS（性能预算在架构 ADR 定义）

## 4. 核心循环

**30 秒循环（室内）**：靠近容器 → 按 E → 进度条 → 获得 loot → 判断背包是否满 / 是否值得继续搜

**5 分钟循环（外出）**：选目标（废弃屋 / 矿洞 / 水塘）→ 路上躲尸群 → 到达后搜刮或采集 → 背包满 → 决定继续贪还是撤

**长循环（一天）**：白天外出积累资源 → 回据点制作/炼金/附魔/打造装备 → 加固工事 → 夜晚防守尸潮 → 次日解锁更高级配方与更远的区域

## 6. MDA 分析

**Mechanics（机制）**：程序化超大地图、容器 loot 表、昼夜时钟、制作配方树、Z 轴多层空间、尸潮聚合 AI。

**Dynamics（动态）**：
- 玩家在"贪心多搜一间房"与"天黑前赶回据点"之间反复权衡 → 产生张力
- 背包容量有限 → 迫使玩家对 loot 做价值判断（要材料还是要成品）
- 矿洞越深产出越好但越难撤 → 深度即风险
- 据点越加固，越敢往远处走 → 正反馈推动探索半径扩大

**Aesthetics（美学）**：目标美学是 **Discovery（发现）** 为主，**Challenge（挑战）** 与 **Fellowship（伙伴/据点归属）** 为辅。8 个制造系统不是堆玩法，是给 Discovery 提供"找到的东西能变成什么"的兑现路径。

## 7. 玩家心理（自我决定论）

- **自主**：不强制路线。8000×8000 里往哪个方向走、先搜刮还是先挖矿、据点建在哪，全由玩家决定
- **胜任**：制造树提供清晰的能力增长曲线（石斧 → 铁镐 → 附魔钢剑），每一次升级都能立刻在数值上被感知
- **关联**：据点是"家"的锚点；NPC 幸存者（二期）提供归属与交换

## 8. 心流与挑战曲线

```
挑战
  ▲                          ▁▁▃▅▇ 夜（尸潮）
  │        ▁▃▅▂     ▁▃▅▂           ▁▃▅▇
  │  ▁▃▂        ▁▃▂      ▁▃▂
  │▁▂                              ▁▃▂ 晨（搜刮残骸）
  └──────────────────────────────────▶ 时间
     昼：低压力搜刮   昏：返程焦虑   夜：高压防守
```

关键是**昼夜落差要够大**：白天几乎不会死，夜晚不回据点基本会死。落差不够，地图再大也只是散步。

## 9. Bartle 受众

- **主要：Explorer（探索者）** —— 超大无缝地图 + 随机房屋 + 容器 loot 直击这类玩家
- **次要：Achiever（成就者）** —— 8 个制造系统 + 装备词缀提供长期目标
- **兼顾：Survivor** —— 尸潮提供威胁
- **不服务：Socializer / Killer** —— 无联机、无 PVP（本期明确不做）

## 10. 世界与地图规格（硬约束）

| 项 | 规格 | 说明 |
| --- | --- | --- |
| 地图尺寸 | **8000 × 8000 格** | 6400 万格，全量驻留内存不可行 |
| 生成方式 | 本地程序化生成，确定性种子 | 同一 seed 必得同一世界；不预生成整图 |
| 分块 | chunk = 64 × 64 格 | 全图 125 × 125 = 15625 块，按需生成 + LRU 卸载 |
| 无缝 | 邻块预取，无加载画面 | 玩家在 chunk 边界不应感知任何停顿 |
| 瓦片 | 等距 2:1 菱形，64 × 32 px | 45° 俯角斜视 |
| Z 轴 | Z 为高度层：地下矿洞 Z<0，地表 Z=0，楼层 Z>0 | 上下楼梯/矿井竖井切换层；渲染按 Z 分层 + 深度排序 |
| 房屋 | 随机生成（位置、户型、层数、容器分布） | 由 chunk 种子决定，可复现 |
| 容器 | 全部可交互，按 **E** 搜索 | 每个容器一次 loot roll，搜索后标记 persistent 已搜状态 |
| 水域 | 湖泊/河流，可钓鱼 | 二期 |

**为什么 6400 万格必须分块**：单格若占 4 字节（地形枚举）全图即 256 MB，叠加实体、容器状态、光照不可接受。必须"生成而不存储"：只存玩家改动过的差异（diff），其余由种子推演——这是架构阶段第一条 ADR 的核心命题。

## 11. Visual Identity Anchor（美术圣经输入）

- **色调**：褪色的暖灰为主（沙尘、锈蚀），危险区偏冷青，夜晚压到近黑蓝 + 暖黄光源（篝火、手电）
- **形状语言**：方块化的废墟轮廓 + 尖锐的残骸边缘；感染者用瘦长不规则剪影，与方正建筑形成对比
- **材质**：磨损、剥落、污渍；禁止高饱和、禁止光滑塑料感
- **可读性优先**：45° 视角下，可交互容器必须有**轮廓高亮**，玩家一眼能看出"这个能按 E"
- **特效克制**：搜刮进度条、掉落物弹跳、血量飘字即可；不做满屏粒子

## 12. 范围分层

**MVP（垂直切片必须做完）**
1. 45° 等距渲染 + 角色八向移动 —— 验收：能在地表跑动，帧率达标
2. chunk 流式生成与无缝拼接 —— 验收：连续跑 5 分钟无卡顿、无加载缝
3. 地表采集（草木 / 废料） —— 验收：能采集并进背包
4. 地下矿井（Z<0）与挖矿 —— 验收：能下井、挖矿、返回地表
5. 随机房屋生成 —— 验收：不同 seed 得到不同布局
6. **容器按 E 搜索** —— 验收：每个容器可搜、有进度条、有 loot、搜过不再重复
7. 基础战斗（近战 + 少量感染者） —— 验收：能打死感染者、会掉血、会死
8. 制作系统（基础配方） —— 验收：材料 → 成品
9. 背包与存档 —— 验收：退出重进，世界改动与背包保留

**二期**
钓鱼、炼金、附魔、武器制作、防具制作、据点建造与加固、尸潮事件、NPC 幸存者、疾病/体温等生存压力。

**明确不做（本期）**
多人联机、PVP、载具、主线剧情任务线、程序化音乐、手柄支持、移动端适配。

## 13. 风险与未知

| # | 风险 | 影响 | 验证方式 |
| --- | --- | --- | --- |
| R1 | 6400 万格 chunk 流式生成的内存与卡顿 | 支柱 P1 | prototype：跑 5 分钟，记录 chunk 生成耗时与驻留内存曲线 |
| R2 | 45° 视角下建筑/角色深度排序错误 | 观感直接崩 | prototype：多层房屋前跑动，人工观察遮挡 |
| R3 | 尸潮规模（数百单位）AI 与渲染开销 | 支柱 P4 | 二期原型：压力测试 N=200/500 的帧率 |
| R4 | Z 轴多层（楼层 + 矿井）的空间导航与相机 | 支柱 P3 | prototype：上下层切换不迷失 |
| R5 | 容器 loot 状态持久化导致存档膨胀 | 存档可用 | 架构 ADR：只存 diff，估算 1 万容器已搜状态的体积 |
| R6 | 纯 Canvas 无引擎，自研渲染/输入/碰撞的成本被低估 | 整体进度 | prototype 阶段只做最小渲染，先验证再扩展 |

## 14. 关键数值（初值，balance-check 阶段调）

| 项 | 初值 | 备注 |
| --- | --- | --- |
| 地图边长 | 8000 格 | 硬约束，不打折 |
| chunk 边长 | 64 格 | 待 R1 验证后可改 32 / 128 |
| 瓦片尺寸 | 64 × 32 px | 等距 2:1 |

| 背包格数 | 24 | 迫使取舍 |
| 感染者昼/夜密度 | 1× / 6× | 制造昼夜落差 |
| 矿井每层产出倍率 | ×1.6 | 深度即风险 |
