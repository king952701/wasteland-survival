# 星海牧场 · 安卓打包说明

## 方式一：GitHub Actions 云端编译（无需安装任何软件，推荐）

### 无需 git：直接网页上传

1. 右键 `hunyuanji\准备上传.ps1` → **使用 PowerShell 运行**
   （或 `powershell -ExecutionPolicy Bypass -File 准备上传.ps1`）
   会生成干净的 `hunyuanji\upload\` 目录：51 个文件、0.44MB，
   已自动排除 320MB 工具链、构建产物和本机 SDK 路径
2. 打开 https://github.com/new 建一个**空仓库**（不要勾选 README / .gitignore）
3. 在空仓库页面点 **uploading an existing file**
4. 把 `upload` 文件夹**里面的 4 项**全部拖进去：
   `.github`、`.gitignore`、`android`、`galaxy`
   —— 注意不要连 `upload` 这一层一起拖进去
5. **确认仓库里有 `.github/workflows/build-apk.yml`**（这一步最关键）；
   若网页上传漏掉了隐藏目录，就手动：
   `Add file → Create new file`，文件名填
   `.github/workflows/build-apk.yml`，把本地同名文件内容粘贴进去
6. 点 **Commit changes**
6. 会自动触发编译 → 打开 **Actions** 标签，看到正在运行的「构建星海牧场 APK」
7. 约 3～5 分钟变绿后，点进去在 **Artifacts** 里下载 `星海牧场-APK`
8. 解压得到：
   - `app-release.apk` —— 正式包（推荐安装）
   - `app-debug.apk` —— 调试包（包名带 `.debug`）

> 以后改了游戏内容：重跑 `准备上传.bat`，再在第 3 步上传覆盖同名文件即可，
> 或者手动点 Actions → Run workflow 重新编译。

> 云端编译已配置好 JDK17 + Android SDK + Gradle 8.5，且会自动把 `galaxy/` 同步进 assets，
> 所以你改完网页代码直接 push 就能拿到最新 APK。

## 方式二：本地 Android Studio

1. 安装 [Android Studio](https://developer.android.com/studio)（自带 JDK + Android SDK）
2. `File → Open` 选择本 `android` 目录，等待 Gradle Sync 完成
3. `Build → Build Bundle(s) / APK(s) → Build APK(s)`
4. APK 输出在 `app/build/outputs/apk/`

## 方式三：命令行（一键脚本）

双击 `打包APK.bat`，它会自动完成：

1. 同步 `galaxy/` → `app/src/main/assets/`
2. 下载并装好 JDK 17（华为云镜像）、Gradle 8.5（腾讯云镜像）
3. 下载 Android cmdline-tools，用 sdkmanager 装 `platforms;android-34` + `build-tools;34.0.0`
4. 编译 `assembleRelease assembleDebug`，打印 APK 路径

> 工具链装在 `hunyuanji/.toolchain/`（约 320MB，只下一次，之后复用）。

### 网络要求

第 3 步需要访问 **dl.google.com**（Android SDK 官方源）。
若你的网络访问不了（很多国内网络会拦截），脚本会明确报：

```
!! Android cmdline-tools NOT available
!! dl.google.com is unreachable from this network
!! platform android-34 missing
```

解决办法，任选一个：

- **开代理后重跑**（脚本已支持自动读代理环境变量）：
  ```
  set HTTPS_PROXY=http://127.0.0.1:7890
  打包APK.bat
  ```
- **改用方式一（GitHub Actions 云端编译）**，不需要访问 dl.google.com。

> Maven 依赖（AGP、androidx.webkit）已在 `settings.gradle` 里配了阿里云镜像兜底，
> 所以即使 dl.google.com 不通，只要能拿到 SDK 就能编译。

## 目录结构

```
android/
  settings.gradle / build.gradle / gradle.properties
  app/
    build.gradle                    AGP 8.1.4，minSdk 26，仅依赖 androidx.webkit
    src/main/
      AndroidManifest.xml           竖屏、硬件加速、无网络权限
      java/com/xinghai/ranch/MainActivity.java
      res/                          图标/主题/启动图（全 XML，无图片文件）
      assets/                       ← 由 galaxy/ 同步而来（m.html + css + js）
```

## 关键实现点

- **存档可靠**：用 `androidx.webkit.WebViewAssetLoader` 把 assets 映射成
  `https://appassets.androidplatform.net/assets/m.html`，页面获得真实 origin，
  `localStorage` 才能持久化（直接用 `file://` 加载时很多 WebView 会禁用 localStorage）。
- **挂机补算**：`onPause` 调 `MGame.onPause()` 存盘并 `pauseTimers()`；
  `onResume` 调 `MGame.onResume()` 按真实时长结算离线收益，锁屏/切后台收益照拿。
- **渲染进程崩溃自愈**：`onRenderProcessGone` 自动重建 WebView 并重载。
- **minSdk 26**（Android 8.0+）：保证系统 WebView 版本足够新，能跑 ES6 与新版 CSS。
- 图标为自适应图标（vector + shape），工程内不含任何二进制图片。

## 改数据/改玩法后

只要改 `galaxy/` 下的网页源码，然后重新打包即可（云端构建会自动同步）。
不需要动 Java 代码。
